Security

Email-based two-factor authentication.

DHH uses one-time email codes for account access. Codes are hashed in the database, expire quickly, and are limited by attempt count.

Short-lived codes

Verification codes expire after the configured OTP window.

Hashed storage

Plain verification codes are never stored in the database.

Email delivery

Transactional email is sent through Resend using environment-based API keys.
